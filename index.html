Innovyria Flatpak repository

Open-source apps from Innovyria, crafted by an autonomous software development lifecycle. Apps run on the GNOME runtime from Flathub and update with flatpak update or GNOME Software.

  • Markdown Editor

    Write Markdown with a live preview: Mermaid, KaTeX, GitHub alerts and Marp slide decks

    Install

    flatpak install --user https://innovyria.github.io/flatpak/io.github._24icewolf42.markdown-editor.flatpakref

    Single file that updates from this repository: io.github._24icewolf42.markdown-editor.flatpak (flatpak install --user --bundle FILE)

Add the whole repository

flatpak remote-add --user --if-not-exists innovyria https://innovyria.github.io/flatpak/innovyria.flatpakrepo
